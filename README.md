# Touchline Bonus Hub

Open dist/index.html to view the site. To host it, upload the contents of dist to a static web host.

The ten illustrative offers live in dist/offers.js. Each entry includes a title, category, reward label, and rules. Array order controls display order. Offer edits take effect when the updated files are served and the page is reloaded.

The offers are fictional. The site displays promotion terms only.
After editing offers, run node build-offers.cjs from this directory to regenerate the individual pages before publishing.
